## ✨ Sobre o Projeto

A Black Fit 19 é uma academia em operação real, e este projeto foi desenvolvido para fortalecer sua presença digital através de uma interface moderna, responsiva e visualmente impactante.

O objetivo foi criar uma experiência profissional para os clientes da academia, transmitindo modernidade, energia e identidade visual forte.
